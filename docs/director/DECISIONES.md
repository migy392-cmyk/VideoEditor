# Decisiones y preguntas

## Decididas por el director
| # | Decisión | Motivo |
|---|---|---|
| D1 | Se amplía el editor actual, no se rehace | Ya analiza, aprende y monta; falta DaVinci |
| D2 | Entrega por **FCPXML + script Lua interno** | Es lo que permite la versión gratis |
| D3 | Sin MCP de terceros para Resolve | Requieren control externo (solo Studio) |
| D4 | El proyecto JSON es la única fuente de verdad | Vista previa y DaVinci siempre coinciden |
| D5 | Modo **Fiel** por defecto, original en pista oculta | Se ve como la muestra y sigue siendo reversible |
| D6 | Sin dependencias nuevas obligatorias | Instalación simple en el PC del usuario |
| D7 | La capa visual la aporta el agente analista mirando fotogramas, no un modelo instalado en el PC | Mejor calidad, cero instalación |
| D8 | Fase 1 = prueba de importación real en el PC del usuario | Es el mayor riesgo |

## Preguntas abiertas al usuario
| # | Pregunta | Si no contesta, se asume |
|---|---|---|
| P1 | ¿Qué versión de DaVinci Resolve tienes (18, 19, 20…)? | La última; se comprueba en la Fase 1 |
| P2 | ¿Entrega "Fiel" (efectos ya hechos) o "Editable" (los pones tú)? | Fiel |
| P3 | ¿Siempre gimnasio vertical ~15 s, o también otros temas/duraciones? | Gimnasio, vertical, 10–30 s |
| P4 | ¿Los videos de muestra son archivos que ya tienes o enlaces de TikTok/Instagram? | Archivos en `workspace\references\` |
| P5 | ¿Quieres textos/subtítulos en los edits? | No; solo marcadores donde irían |
